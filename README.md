# PromptNote

Vintage tasarımlı, zarif bir not alma web uygulaması.

🔗 **Canlı Demo:** [mazyleyn.github.io/PromptNote](https://mazyleyn.github.io/PromptNote/)

## Hakkında

PromptNote, düşüncelerinizi eski/vintage stilinde tasarlanmış bir arayüzde not almanızı sağlayan basit bir web uygulamasıdır.

## Kullanım

- Notunuzu yazı alanına yazın
- 🖊️ Kalemi sürükleyin
- 🔖 Mühürü çevirin
- ⭐ Yıldıza tıklayın

Uygulama herhangi bir kurulum gerektirmez, [buradan](https://mazyleyn.github.io/PromptNote/) doğrudan tarayıcı üzerinden kullanılabilir.
